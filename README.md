# Twitch Vertical Layout

縦配置のモニターで Twitch を開いたとき、チャット欄を上、配信画面を下に並べる Chrome 拡張です。

## インストール

1. Chrome で `chrome://extensions/` を開きます。
2. 右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. このフォルダを選択します。
5. Twitch の配信ページを再読み込みします。

## 動作

- 画面が縦向きのときだけ有効になります。
- Twitch の配信ページで、チャット欄が上、配信画面が下に表示されます。
- 左のフォロー中バーは非表示になり、チャット欄と配信画面は全幅表示になります。
- 配信下の概要欄などは、縦配置で見やすくするため非表示にしています。
